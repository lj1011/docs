# 创意准则 v0.2（草稿，Keven 已拍板 8 项）

> **状态**：v0.2 可迭代草稿，不是定稿。v0.1 的 8 个开放问题已由 Keven 于 2026-10-19 拍板（见第七节），其余规则仍会在实际配合中一条条澄清、修改、删减。
> **来源**：《故事灵感库（拉片大师）》23 张卡（`internal/story-inspiration-cards-readme.md`，建库 2026-10-19）。
> **用途**：拉片的目的是吸收好创意、好故事，作为灵感积累。本准则把 23 张卡里反复出现的东西整理成可以打分、可以复用、可以证伪的规则，供「创意桌」（`shortform-desk`）出点子、写故事、写导演阐述时使用，也供 Keven 审稿时对照。
> **两条腿并列**：叙事／策略创意 与 视觉创意（美术、运镜、光色、剪辑节奏、屏字）同等重要，打分、骨架、手法、反模式都按两条线分别写。

**标注约定（全文通用）**

| 标注 | 含义 |
|---|---|
| `#NN 片名` | 卡片证据：灵感库第 NN 张卡，片名用索引里的灵感名 |
| **待补** | 卡片或现有资料里没有的信息，不编 |
| **推断** | 根据卡片归纳或推理得出，卡片原文没有直接写 |
| **待验证假设** | 没有卡片证据支撑的规则，必须先测试或由 Keven 拍板 |
| **已拍板** | Keven 明确决定的规则，按决定执行，改动需 Keven 同意 |
| 弱证据 | 来自未拉片或配方卡（#20、#21、#22、#23），只能辅助，不能单独撑一条准则 |

**Keven 已拍板的创作立场（2026-10-19，详见第七节）**

| 项 | 规则 |
|---|---|
| 项目类型 | 每个项目先标 **品牌片** 或 **自创故事**。不预设任何具体品牌：可以是无品牌的自创故事，也可以是任意指定品牌 |
| 暗黑／惊悚／暴力边缘调性 | **品牌片一律不用**（一票否决）；**自创故事可以用**，但刀刃抵喉、斩击特写仍禁用 |
| 情绪基调 | 不设固定优先级，也不预先排斥，服务于故事需求 |
| AI 质感 | 不限制：明显 AI 感、超现实变形或写实无 AI 感都可以，服务于故事 |
| 打分及格线 | 叙事 ≥7/12、视觉 ≥8/14、合计 ≥16/26，N1 和 V1 不能为 0 |
| 成功标准 | 现阶段以 **Keven 的审美判断（过稿与否）** 为主验收；投放数据日后选填 |
| 禁区 | 维持现有禁区，暂不新增（见 1.3） |
| 导演阐述 | **段落级**，**第一人称导演口吻**（“我……”），不写逐镜焦段参数表 |

**卡片证据强度**：#01–#19 有拉片产物（#04 带导演阐述和预演；#05 只拆了前 60 秒；#09 按快速档合并，未精标）。#20 是工具演示，故事性弱。#21 是模板示范，事实部分来自创作者自述。#22 没拉片，只有探针 flag。#23 是配方卡。**23 张卡都没有播放或完播数据（待补）**，所以本准则里的“好”目前只代表“结构上值得学”，不代表“数据上已证明有效”。

## 二、故事骨架库

每个骨架写：核心机制、戏剧节拍、适用场景、卡片、证据强度。适用场景里没有卡片原文支持的部分标「推断」。点子和故事要标出用的是哪个骨架（如 `S07`）。

### S01 · 镜像问题
- **核心机制**：整片只有一个问题，主角穿过多个世界去找答案，答案是“你自己”。一个问题让风格拼盘有了叙事理由。
- **戏剧节拍**：抛出问题 → 世界 1／2／3（每个世界一种材质）→ 回到起点 → 静音屏息 → 镜像揭晓 → slogan。
- **适用场景**：品牌主张从“我们很强”翻成“你是作者”；多卖点、多场景要串成一条片（推断）。
- **卡片**：#01 你就是 King（已迁移为海信《真彩寻光》）
- **证据**：已拉片，单卡骨架。

### S02 · 双时间并行＋停格
- **核心机制**：环境在快进，主体（屏幕／人）在实时；全片唯一的实时停格是一口呼吸。
- **戏剧节拍**：开场时钟 → 多条时间线同步推进（时钟、色温、人流、营业状态）→ 关键时刻冻结十几秒、音乐撤空 → 恢复 → 熄灯后主体还在。
- **适用场景**：一天、一季、一生之内的卖点轮换（如正午抗反光、夜里控光）；“始终如一”类主张（推断）。

### S04 · 剥夺→剩余物重做→公共空间

## 三、视觉手法库

### 3.1 美术
- **一个镜头＝一个文化符号＋一种科技材质**：红缨枪配塔吊、舞狮配 LED 眼、机械手下围棋（#02 画里东方）
- **一个世界一种材质，换材质就是换场景**：纸城、体素、糖果、星空（#01 你就是 King）
- **本地装饰托住品牌色**：拱门马赛克、ikat 托住品牌冷蓝（#14 罐即催化剂）
- **神圣几何做场景骨架**：注连绳、狛犬、鸟居、神木（#08 诱饵→假失败）
- **重复体／克隆人墙**：黑高领群体同步歪头（#12 空心胜利）
- **高辨识服装从头穿到尾**，配件逐段变形成母题（#13 服装锚点游记）
- **把降质当风格**：80 年代 Betacam 画质、台标、字幕条、VCR PLAY 片头（#23 怀旧 VHS 新闻广告，弱证据）
- **结果物当物证**：硬糖爆开后留在地上（#11 伤害变糖果）

### 3.2 运镜
- **机位不动，只换屏内内容**，用换片代替剪辑（#03 一天的光：22 段里 15 段机位不动）
- **动作和机位不变，只换画面**，用来证明“只变了这一个东西”（#17 欲望阶梯）
- **极低机位／英雄角／轮毂特写**（#07 下班传送门、#15 冲击即能量）
- **沿中轴前推，穿过对称圆拱**（#19 每镜一个动词）
- **地面低机位，把观众放进他者视角**（#06 备用爱人）
- **末镜拉远，揭示空座**（#12 空心胜利）
- **Dutch 角、甩镜、圆形门洞、鱼眼、入罐变形**做转场（#14 罐即催化剂）
- **景别阶梯**：同一造型 24→70→135→200mm 逐级收紧（#18 错误结果钩）
- **碎玻璃仰拍交代坠落母题；镜头隧孔里一只眼回视**（#04 先有职业）

### 3.3 光色
- **单色系统**：车漆、底盘光、胎烟全是泡泡糖粉（#07 下班传送门）
- **互补色贯穿全片**：红青（#02 画里东方）

- **色温叙事**：墙面 6,700K→3,600K 跟着一天走（#03 一天的光）
- **主体守色，环境吃光**：灰卡墙吃环境光，屏幕守住自己的颜色（#03 一天的光）
- **冷暖对撞**：荧光绿主体对冷蓝雾林（#15 冲击即能量）

- **平亮棚灯＋深焦**做新闻感（#23 怀旧 VHS 新闻广告，弱证据）

### 3.4 剪辑节奏
- **战段密剪**：每镜约 0.67s（#02 画里东方）

### 3.5 屏字
- **全大写动能字幕**，静音刷也能看懂（#10 第三颗药）
- **手机 UI 承担叙事节拍**，不靠对白（#04 先有职业）

### 3.7 时间压缩与停格
- **倍速快进＋实时主体**：时钟 ×110～×930（#03 一天的光）
- **唯一的停格段**：时钟和计数冻结 13 秒、音乐撤空（#03 一天的光）

## 四、方法论：解码 → 映射 → 生成 ＆ 单变量可证伪变体

### 4.1 解码（从拉片卡拆出可迁移的零件）

对一张卡回答下面 6 个问题，写不出来的写「待补」，自己推的写「推断」：

1. **规则／问题**：一句话说出这条片的规则（对应 N1）。
2. **骨架**：对应第二节哪个 S 编号？对不上就提议新骨架。
3. **机制**：为什么它有效（反转、停格、催化剂……）。
4. **视觉锚点和视觉系统**：锚、色板、运镜、节奏、屏字各写一句。
5. **呼吸点**：停格／静音／真失败在哪一秒。
6. **不可借清单**：音乐、HUD、屏内片段、暴力画面、致敬 IP、虚构数据。

### 4.2 映射（换皮，不换骨）

- **保留机制和节拍**，替换：主角身份、世界／场景、视觉锚、兑现物、终局字。
- 每个替换写成一行：`原片 X → 我们 Y（理由）`。
- 先确定项目类型：**品牌片**（任意指定品牌）或**自创故事**（无品牌）。不预设任何具体品牌（已拍板）。
- 品牌、型号、slogan、合规没给的一律「待补」，不编。
- 竞品一律换成品类痛点（#21）。
- 例子（卡片里已有的映射，仅作示例，不代表默认品牌）：#01 的“牌面映出自己”→ 海信“屏里是你家”；#03 的“展厅一天”→ 海信“客厅 06:00–23:00”，正午对应抗反光、夜里对应控光。

### 4.3 生成（基准版＋单变量变体）

1. 先出**基准版**（完整故事＋镜头表）。
2. 再出 **2–3 个变体，每个变体只改一个变量**。可改的变量举例：钩子位置（结果前置／顺叙）、反转有无、停格有无、视觉锚颜色、屏字有无、品牌出现时间、配乐卡点方式、时长、骨架里的某一拍。
3. 每个变体附一条**可证伪假设**，格式固定：

> **变量**：只改了什么（一个）
> **改法**：从 A 改成 B
> **假设**：改成 B 后，Keven 会更倾向于过稿（或：哪一处观感会变好／变差）
> **证伪条件**：如果 Keven 审完认为 B 不比 A 好，或直接不过稿，假设不成立
> **指标**：**Keven 审美判断（过稿与否）**，现阶段主验收标准（已拍板）；3 秒留存、完播率等投放数据日后选填

卡片里已有的单变量变体例子：#01 变体 C“去掉反转”、#03 变体 B“无停格”、#03 变体 C“无 HUD”、#02 变体 B“锣鼓卡点”。
**注意**：23 张卡都没有表现数据（待补），所以变体测试目前没有历史基线，第一轮测试的结果就是基线。

### 4.4 每次故事交付必须附「导演阐述」

没有导演阐述的故事不算交付，创意桌里不能批准。**写到段落级，用第一人称导演口吻（“我想……”“我选择……”），不写逐镜焦段参数表**（已拍板）。模板：

```
【导演阐述】（第一人称，每项一段）
立意：我想让观众相信什么、感受到什么，这条片的规则／问题是什么。
视觉锚点：我选了哪个唯一的锚，它在片中怎么出现、怎么变化。
运镜·光色·节奏：我用什么机位策略、色板与光的变化、剪辑节奏，呼吸点放在哪里、为什么。
核心假设：我赌的是什么；如果 Keven 审美判断不认可，我先改哪一个变量。
借鉴与边界：我借了哪张卡的什么机制（卡号），明确不借什么。
待补／推断：我还不知道的信息和我自己推断的部分。
```

## 六、人机配合方式

### 6.1 项目（AI 创意导演／创意桌系统）负责

- 按本准则出点子：每条标**骨架编号**、**视觉锚点**、**借鉴卡号**；自查一票否决项。
- 先确认项目类型（品牌片／自创故事），品牌片自动执行暗黑调性一票否决。
- 按第一节问题清单给自己的候选**预打分**（只是参考，不替 Keven 决定）。
- 写故事时套骨架节拍，交付时**必附导演阐述**和**单变量变体＋可证伪假设**。
- 所有不知道的写「待补」，推断的写「推断」，没有卡片证据的规则写「待验证假设」。
- 记录 Keven 每次的选择、加星、拒绝原因，作为下一轮的输入。
- 每积累一批反馈，提出本准则的**修订提案**（改哪条、依据是哪几次反馈），由 Keven 批准后才改版本号。

### 6.2 Keven 负责审核

- 选点子（必须人选，系统不能替选）。
- 拒绝时写一句原因（会进入下一轮，也会进入准则修订）。
- 审导演阐述：立意对不对、视觉锚点够不够强、核心假设值不值得测。
- 对每个变体做审美判断（过稿与否），这是现阶段变体假设的验收结果。
- 批准故事（没批准不能进渲染）。
- 拍板第七节的开放问题；批准或驳回准则修订提案。

### 6.3 准则怎么迭代

1. **每次反馈都留痕**：创意桌把加星、拒绝原因、改稿保存在项目里。
2. **攒够再改**：同一类拒绝原因出现 3 次以上（这个阈值是推断，待 Keven 确认），系统提议新增或修改一条反模式或判断标准。
3. **新拉片卡进来**：追加到灵感库后，系统检查它支持哪条共性、哪个骨架，或提议新骨架；单卡支持的规则保持「单卡」标注。
4. **待验证假设转正**：有测试结果或 Keven 明确拍板后，去掉「待验证假设」标注，并在修订记录里写依据。
5. **版本号**：v0.x 都是草稿；Keven 认为可以作为默认标准时才升 v1.0。

## 七、Keven 拍板记录与开放问题

### 7.1 已由 Keven 拍板（2026-10-19）

1. **审美底线**：暗黑、惊悚、暴力边缘调性（#06 家庭惊悚、#11 黑色幽默、#08 打斗与血）→ **品牌片一律不用，自创故事可以**；刀刃抵喉、斩击特写在两类项目里都禁用。
2. **品牌边界**：**先不局限具体品牌**。项目可以是无品牌的自创故事，也可以是任意指定品牌；不再假设海信为默认品牌。
3. **情绪基调**：**都可，主要服务于故事需求**；不设固定优先级，也不预先排斥某种基调。
4. **打分权重和及格线**：**同意**。叙事 ≥7/12、视觉 ≥8/14、合计 ≥16/26，N1 和 V1 不能为 0，转为已拍板规则。
5. **禁区**：**暂时不定新增**，维持原片音乐、HUD、屏内片段、暴力特写、点名竞品、虚构数据、未查版权的致敬 IP。
6. **成功的标准**：**先基于 Keven 自己的审美判断**。单变量变体的可证伪假设以 Keven 审美判断／过稿与否为主验收，投放数据日后选填。
7. **AI 质感立场**：**不限制，服务于故事**；明显 AI 感、超现实变形或写实无 AI 感都可以。
8. **导演阐述的颗粒度和口吻**：**段落级，第一人称导演口吻**；不写逐镜焦段参数表。

### 7.2 新的开放问题（v0.2+，实践中遇到再补）

- 6.3 里「同一类拒绝原因出现 3 次以上就提议修订准则」的阈值是推断，待 Keven 确认。
- 其余实践中遇到再补（待补）。
